Add a Kiro CLI agent provider. Use `kiro(model, options?)` as the `agent` in `run()`, `createSandbox().run()`, and worktree runs. Authenticates via `KIRO_API_KEY` (Kiro Pro or higher), supports `--effort` and `--agent` flags, and is available as an option in `sandcastle init`.
